# 查房表更新工具 v1.0

发布日期：2026-07-11

## 本版重点

- 重做主界面为工作台布局，导入文件、床位维护、处理状态更清楚。
- 修复导入 Excel 后卡片显示杂乱的问题。
- 修复底部按钮在处理完成后被状态文字挤压、移位或不显示的问题。
- 将“行高”改为“最小行高”，单位显示为 Excel 实际使用的“磅”。
- 调整导出 Excel 的自动行高算法：以设置值为下限，内容多时只加高到刚好够显示。
- 优先参考原查房表行高，避免已有行被不必要地撑高。
