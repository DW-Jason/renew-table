# 查房表更新工具 v2.0 Win7 兼容版

发布日期：2026-07-11

## 构建信息

- Python：3.8.10
- PyInstaller：6.13.0
- 目标：Windows 7 兼容环境优先

## 本版重点

- 启动性能优化：Excel 读写库改为处理文件时再加载，主窗口打开前不再提前加载 openpyxl/xlrd/xlwt。
- 打包体积优化：排除未使用的可选大模块后，exe 从约 33.2MB 降到约 14.3MB，低配电脑启动压力更小。
- 床号包含 `zr` 的行会排在普通床号后面。
- 最终行高规则调整为：以设置的“最小行高”为下限，内容多时只加高到刚好够显示。
- 行高设置支持直接输入，也支持 `-` / `+` 微调；开始处理前会自动保存当前设置。
- 病区、医疗组、床位选择会保存到用户本机配置目录，修复 onefile exe 关闭后配置丢失的问题。
- 打印格式会清空页眉页脚，并将上、下页边距和页眉页脚边距设为 0。
- 导出时不再沿用原查房表的数据行高度，避免设置了较小行高却被原表行高顶回去。
- 缺少必要列的 Excel 会给出明确错误提示，不再因为部分匹配表头导致内部异常。
- 保留 v1.0 的工作台界面、导入状态、底部按钮固定布局等修复。
